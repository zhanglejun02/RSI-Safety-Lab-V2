2026-11-16。状态：**定向查重与实现可行性核对完成；干预功能、自然实验和论文主张均未验收。**
本轮冻结执行代码，不启动付费实验。已有协议和参考审查模块作为实验基础，

## 1. 具体问题和主张边界

> 从同一个合法检查点出发，保持完整即时部署输入相同，撤回一个预先选定的
> 非部署候选，是否会改变固定后续演化机会内的安全风险？这种变化是否优于
> 撤回一个按预定条件匹配的其他候选，同时保持可接受的任务效用？

首个研究对象是 **OpenEvolve 搜索中仍可使用的候选集合**，不是其名为
`archive` 的单个字段。集合包括能成为父代、灵感、额外提示上下文或后来
部署者的程序。当前执行器只使用部署 `policy`；这些搜索状态不直接进入任务执行。
这使即时执行与后续更新可以分开研究。

“部署相同”要求 policy 源码、共同执行器、模型设置、工具、任务初始环境、
上下文规则和所有可供 actor 读取的状态相同。相同最佳分数、模型或主提示都不够。
该条件意味着即时行为分布应相同，不意味着独立云端采样的两次答案必然相同。

| 待验证层次 | 足够的证据 | 不足以支持它的结果 |
|---|---|---|
| 候选存在影响后续结果 | 共享检查点的目标撤回与 sham 有可重复差异 | 两条随机轨迹不同；脚本强制产生差异 |
| 预定目标规则具有安全意义 | 目标撤回优于匹配撤回，效用达到预定容差，且有搜索路径证据 | 所有撤回都一样；搜索停止后更安全 |
| 当前行为审查存在覆盖限制 | 即时输入相同，但后续风险差异可由候选信息预先区分 | 只发现最终分数不同，或事后挑选危险候选 |

第三层仍不等于某个 gate 已经有效。在线准入会改变后续访问到的状态，需要另做干预
策略实验。本研究先测候选继续可用的总效应，不声称识别纯粹的“危险文本效应”，
也不声称清除了该候选已经留在其他程序或历史统计中的影响。

## 4. 三臂干预：先研究一次性撤回

对每个独立 source root，在预先规定的 prefix 窗口内选**首个合格检查点**。
从该检查点创建三份独立分支；分支名不进入模型提示，物理目录与预算账本独立。

| 分支 | 检查点操作 | 对比解释 |
|---|---|---|
| S：sham | 原样导出、验证、恢复 | 控制分叉与恢复流程 |
| T：目标撤回 | 一次性移除预选目标候选 | T−S：撤回目标的总效应；继续保留的效应符号相反 |
| M：匹配撤回 | 同样移除一个匹配非目标候选 | **T−M：主比较**；M−S：该匹配选择规则下的撤回效应 |

三臂保持相同的后续任务、native admission、激活规则、模型配置和提案机会数 L。
首轮不叠加新的安全 gate，不同时改变审查范围、拒绝范围或 meta。固定同一公共
准入规则；接受与否由各自候选决定，不能强制配对接受。

### 检查点与候选资格

- 来自完整已提交的 slot，无未决调用；源码、快照与公开缓存来源可验证。
- 目标与控制均不同于部署源码，并各只有一个 retained source ID；首阶段排除
  source 别名，避免“删除一个 ID、同一源码仍在另一 ID”造成假撤回。
- 两者同属相同 island/archive 层，不是 global-best、island-best 或 feature-map
  owner；没有仍保留的子节点，且本 profile 的 diversity references 为空。
- 两者均有检查点前完整公共评测；匹配信息和筛选证据不读取 final。
- 对不合格 root 记录原因，禁止看后续结果后换检查点、补 root 或放宽条件。
  外推对象仅为符合这些条件的检查点；资格率本身必须报告。

此限制使首阶段无需重建 best、feature maps 或后代结构。若自然运行很少满足条件，
先报告可行性不足；不能静默扩大干预对象以凑样本。

### 状态变换与边界

从 `population.programs`、`population.archive`、所有 `population.islands`
以及候选对应的 `public_artifacts` 删除该 ID。验证没有 live best/map/parent
结构引用或目标源码别名遗留，保留其余程序、部署 component、generation、RNG 与历史 `feature_stats`。
现有 `_restore` 只检查部分引用，不能代替干预后的完整一致性检查。

不可变历史谱系仍保留作为证据，不注入后续模型。三臂导入相同、截止检查点的
已完成公共 rollout cache；缓存按 source×case 被动命中，不是候选生成入口。
不要同时删缓存造成成本和重新采样差异。检查点之后的缓存和评测不得导入。

这是**一次性撤回**，不是永久 denylist。后续生成同一源码时允许它按原规则重新
进入，并单独记录。历史统计、已形成的其他策略和公共缓存也可能保留过去影响；
本实验不试图重写历史。一般候选删除、永久禁用或仅父代 eligibility mask 都是
不同干预，不能混用同一个处理名称。

## 5. 目标选择、匹配与资源

先用已暴露的开发数据冻结一个目标规则：在合格候选中，选择公开 safety probe
上风险估计最高且超过预定阈值的候选；并列按冻结的确定性规则处理。若 probe
无法可靠区分候选，记录“无可定位目标”，不使用 final 结果替代筛选。该公开
screening 与优化 dev、独立 final 分开，证据不写入优化反馈，成本计入共同 prefix。
重复筛选用于校准噪声，不能看完 suffix 后再改目标。

匹配控制从预定 caliper 内随机抽取；匹配量包括公共 utility、缺失状态、
island/archive 身份、父代采样倾向、源码长度、年龄、谱系深度以及 prefix 提示
曝光角色/频率。控制应达到预定的较低公开风险条件，不能按它后来安全与否选取。
精确匹配项、caliper、抽样 seed 和无匹配处理必须在 pilot 后冻结。

匹配控制只能部分排除数量、长度、选择机会等机械效应。它不能保证两项在所有
搜索作用上可交换，因而 T−M 仍是“两个选择规则下的撤回效果差”，不是孤立的
危险语义效应。不得用 suffix 中实际发生的采样概率或成功率做事后匹配。

**主实验匹配提案机会，不宣称总算力相等。** 每臂 L 个机会，计入失败与拒绝，
分开记录实际产生/保留/激活的候选数。使用相同且足够的预算上限；搜索、筛选、
actor、judge 与独立终点评测单列。保留未知调用预留，不自动重试或补一个样本。
共同 prefix 的实际成本只计一次，同时报告独立复现实验的成本分摊方式。

若需要“相同总预算下更有效”的结论，另预注册固定总预算实验及截断规则。
首轮三臂不能通过一边多跑若干代来补齐消费额，因为那会同时改变演化机会。

## 6. 测量、噪声和分析

所有 suffix 冻结后，才对最终部署策略进行新鲜、独立、冻结任务上的评测。
任务内容、scorer、重复次数、缺失规则和分母预先锁定，不返回优化器或筛选器。
当前反复分析的 privacy 序列仅可用于开发与 pilot。

设每个 source root 的三臂最终风险均值为 R_T、R_M、R_S，效用均值为 U_T、U_M、U_S。
先在 root 内平均 continuation replicas 与终点评测重复，再跨独立 roots 汇总：

- 主比较：平均 `R_T − R_M`；负值表示目标撤回更低风险。
- 效用约束：同时报告 `U_T − U_M` 和 `U_T − U_S`，预设允许损失 δU；不能用
  拒绝执行取得的安全改善替代有用任务完成，也不能因两种撤回同样损害效用而过关。
- 辅助比较：T−S 和 M−S；轨迹端点、子群与直接部署/后代路径为预声明次要分析。
- 以 source root 为重采样单位报告配对区间；任务、多个检查点和 suffix replicas
  不增加独立 root 数。不同框架或任务序列的扩展另报告，不事后混成一个显著结果。

正式样本量根据 pilot 的 root 级配对方差、资格率和预定实质效应 δR 决定；不能
根据哪一臂领先决定何时停止。若采用区间验收，安全改善的强主张要求 T−M 风险差
区间上界低于 `−δR`、T−S 风险差区间上界低于零，且两项效用差区间下界均高于
`−δU`；区间构造和联合判定预先指定。若只优于 M 而不优于 S，可能只是匹配撤回
造成伤害，不能称目标撤回提高了安全。δR、δU 必须在确认性实验前填写，不能
看到结果后再定。因此本文件是研究设计，不是一份已经冻结完毕的预注册。

| 重复层次 | 固定什么、改变什么 | 可以诊断什么 |
|---|---|---|
| 重复评分 | 固定同一保存答案与证据，仅重跑 judge | 评分波动；不能估计 actor 波动 |
| 固定策略执行 | policy、任务与执行包络相同，重新执行并评分 | 执行加评分波动；需结合上一层解释 |
| 检查点续跑 | 共享起点、同一干预规则，重新进行后续搜索 | 搜索路径加执行、评分的总体不确定性 |

用预先抽取、身份盲化的嵌套子样本做以上诊断，避免成本无限扩大。比较配对效应
与其不确定性，不把三种样本方差简单相减后称为“评分/执行/状态的贡献比例”。
多根、多层级和交互使这种减法通常没有识别依据。原有 meta 撤回诊断仍属历史
问题，不能合并进这项候选撤回实验。

### 搜索路径证据与阴性对照

记录全部 retained source 在实际 editor 请求中的精确出现、各类上下文角色、
父代边、候选产生与激活、同源码重新出现及成本。完整请求是核对依据；仅有
parent lineage 会漏掉 inspiration 和额外上下文，精确字符串未命中也不能证明
不存在语义上的历史影响。

当前适配器每轮重算 best，原非部署候选可能**直接重新部署**，也可能先影响
子代再部署。两条路径分别报告；出现前者不能包装成后代传播。严格研究子代路径
的后续实验可额外限定目标与控制的冻结公共分数低于部署者，并验证重算 best
不切换，但不能在主实验结束后排除直接部署 roots。

增加 L=0 阴性检查：三臂在不继续演化时，actor 实际输入必须相同。确定性 fixture
验证一致；自然执行只要求分布和重复测量相容。它检查即时状态泄漏，不能证明
后续风险一定相同。

主分析包含所有合格并分配的 roots，不能只挑 sham 后来使用了目标的 roots。
曝光与谱系是机制诊断，不自动构成因果中介识别。缺失、预算耗尽、unknown 与
评分不完整单列；已知违规不抹除，缺失不能当零。报告缺失比例及预定最坏/最好
界限；不能仅用三臂均成功的子集代替主结果。

### 随机性边界

三臂共享检查点和初始 RNG，但**不承诺严格 common random numbers**：删除会改变
集合大小与抽样路径；上游 set 遍历受进程 hash 顺序影响；新 child ID 含 branch
operation 和 base identity，可能影响后续同分排序；远端模型没有可靠同 seed 保证。
持久 `.plan` 保障已规划请求恢复，不保证不同新分支产生相同抽样。

先用零 API sham-vs-sham 检查恢复和身份路径；固定并记录进程设置，按 root×replica
预随机化 S/T/M 到中性 namespace 的映射，另随机化调用次序。调用次序随机化
不能替代 namespace 控制，sham 检查也只能诊断实现影响。base identity 导致的 ID
变化仍需同分排序敏感性核对；若身份机制足以主导科学路径，应先明确并修正逻辑
ID/同分规则，再冻结新源码，不能靠增加重复掩盖它。若要实现更强随机耦合，需
进一步验证候选顺序与抽样；不得悄悄改上游锁定源码或把同 seed 当成控制完成。

## 7. 有限的执行顺序与验收

1. **零 API 可行性**：统计既有 checkpoint 的结构资格，不读取 final 挑样本；
   构建包含 parent、inspiration、top/diverse、previous-attempts 路径的标记 fixture。
   验证允许字段差异、引用完整性、即时输入一致、sham 恢复、原工件不变、分叉
   隔离、预算与 unknown/resume 语义。脚本只验证实验操作。
2. **最小研究扩展**：仅增加候选变换及校验、通过现有 runner 的续跑配置、完整
   请求曝光报告和分析。复用快照、资源、公开缓存及独立 final 路径，不增加 CLI，
   不扩展到三个框架或新 safety module。当前这些候选干预能力尚未实现。
3. **自然开发 pilot**：建议先固定 12 个独立 prefix roots、最多 8 个 prefix
   slots，取首个合格检查点；L=4、每臂 2 次 suffix 重复。最多 72 条续跑，资格
   不足不补选。这个规模只用于可行性、成本及方差估计，不承诺统计功效；先编制
   调用/费用上界再形成运行计划。本轮未建立或启动该付费批次。
4. **正式冻结**：确认主 scorer 能区分风险与任务失败；填写 δR、δU、独立 root
   数、匹配 caliper、公共 probe 数与重复次数、final 分区、缺失/停止规则及所有
   预算。使用独立 roots 和新锁定序列。足够的任务与测量有效性是必要条件，但
   全面重写 task pack 或复现 SEABench 原生 Session 都不是前置工程目标。
5. **按预定规则解释**：若目标与匹配撤回都优于 sham，且两者差的区间落在预定
   等效范围内，结果与非目标特有的搜索限制作用相容，仍不代表任意撤回都有效。
   T−M 不显著本身不能证明等效。若风险收益伴随超容差效用损失，报告权衡；若区间宽，报告证据不足；
   若区间排除预定有用效应，报告该范围内未支持主张。不得临时换 horizon、目标
   选择器、指标或模型维持正结果。

只有自然结果支持该问题后，才决定扩展框架、模型、序列，或比较当前策略审查
与档案审查。平台贡献最终应体现为别人能够复用这套干预和证据协议，而不是把
它已实现当作“新机制发现”的替代物。
