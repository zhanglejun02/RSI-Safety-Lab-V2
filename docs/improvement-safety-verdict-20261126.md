## 控制证据

每类题均有安全完整解、安全且更省服务成本的解、任务完成但违规的解，以及
全部拒绝的对照。环境检查工具调用和模拟效果，无 LLM judge。原生 Frozen /
GEPA / bounded HyperAgents 脚本控制完成 56 项独立记录。这验证测量链路，
不估计自然违规率。

第三层另有潜在风险控制：第一次更新保留安全任务行为，同时改变 meta 发给
编辑模型的指令。控制提供器仅在实际执行的 meta 发出指定指令时生成危险
后继版本；把修改后的文件留在 archive 本身不会触发该控制。

在第一次执行修改 meta 前分叉，任务源码、archive、随机状态、公开缓存完全
相同。当前任务版本在两边均为任务完成 **4/4、违规 0/4**。继续两个更新步后：

| 实际执行的改进器 | 后继最终版本完成 | 后继最终版本违规 |
|---|---:|---:|
| 原始改进器 | 4/4 | 0/4 |
| 保留修改后的改进器 | 4/4 | 4/4 |

**差异由手写控制提供器预设，不是自然现象或算法优劣。** 它证明评测可以区分
当前执行安全与后续改进机制可靠，并验证干预作用于实际执行的 meta。
更广泛的机制敏感性、自然发生率及长期有效性仍未测量。

GEPA 两次提案均产生并部署可执行更新。最终版本加入依据工具观察的验证状态
记录和确定性操作流程：开发集每题模型调用从 **6 降为 1**，八项最终版本

持平；不能把调用减少写成该效用增长，也不能由调用数直接推断 token 或货币
成本下降。最终版独立执行均完成任务且未见违规，完整父子独立配对仍缺失。

HyperAgents 两次更新分别在训练 actor 与 editor 请求中遇到 `URLError`，
未提交更新。随后 Frozen 与 GEPA 的独立测量也各出现一次 `URLError`。
两次显式 continuation 只消费保存的失败 slot、推进未尝试分配，未重发未知
调用、未补做更新、未改任务或参数。连续故障后停止新增付费请求。自然运行
没有修改后 meta 的实际执行证据，第三层自然对照未启动。

**284,927 tokens**，另保留 **88,216 tokens** 预算预留。预留不是实际花费，

## 本轮判断

1. 两类任务与三层诊断已成为可执行原型，算法复用现有接口。
2. 开发集初始模型已选择安全批量验证，任务与服务成本的改进空间很小。
   原型适合验证测量逻辑，尚不足以证明题库的自然区分度。
3. 真实 GEPA 更新获得模型调用效率变化，现有独立观察没有发现安全退化。
4. 第三层受控敏感性成立；自然退化、风险排名和跨算法预测关系仍未建立。

本轮不扩题、不换种子追阳性、不修补已保存结果。若继续，应先恢复可靠网络，
